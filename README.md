# 🍞 Rafa Delícias Artesanais

Loja online desenvolvida para a **Rafa Delícias Artesanais**, permitindo que clientes façam encomendas de forma simples e prática diretamente pelo celular.

---

## 📌 Sobre o projeto

Este projeto foi criado para modernizar as vendas da empresa, oferecendo um catálogo online organizado, carrinho de compras e envio automático dos pedidos pelo WhatsApp.

O objetivo é facilitar o atendimento, aumentar a presença digital e proporcionar uma melhor experiência aos clientes.

---

## ✨ Funcionalidades

### 🛍️ Loja Online

- Catálogo organizado por categorias
- Produtos com imagens
- Carrinho de compras
- Alteração de quantidades
- Observações do pedido
- Escolha entre entrega ou retirada
- Cálculo automático do frete
- Pedido enviado diretamente para o WhatsApp

---

### 📱 Experiência do usuário

- Interface moderna
- Layout responsivo
- Navegação simples
- Compatível com celulares, tablets e computadores

---

## 🛠️ Tecnologias utilizadas

- React
- Vite
- JavaScript
- CSS
- LocalStorage

---

## 🚀 Como executar

Clone o projeto

```bash
git clone https://github.com/felipeniendicker/rafa-delicias-artesanais.git
```

Instale as dependências

```bash
npm install
```

Execute

```bash
npm run dev
```
